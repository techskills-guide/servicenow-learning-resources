# ServiceNow Learning Hub

An independent educational resource with practical ServiceNow guides for ITSM, ITOM, CMDB, HRSD, platform learning, AI and career development.

## Website

Once GitHub Pages is enabled for the `main` branch and `/(root)`, the site should be available at:

https://techskills-guide.github.io/servicenow-learning-resources/

## Structure

- `index.html` — homepage with latest articles listed first
- `blog/` — educational articles
- `assets/style.css` — responsive layout
- `about.html` — editorial scope and disclosure
- `robots.txt` and `sitemap.xml` — crawl guidance and URL discovery

## SEO notes

Pages include titles, descriptions, canonical URLs, Open Graph metadata, internal links and Article/WebSite structured data where appropriate. Metadata and sitemap URLs assume the GitHub Pages project URL above; update them if the publishing URL changes.

Google Search Console ownership verification must be completed by the site owner. Add the site as a URL-prefix property, verify it using an available method, and submit the sitemap at `sitemap.xml`. A verification token must come directly from Search Console; never invent one.

## Editorial principles

Content is educational and not official ServiceNow documentation. Confirm feature availability, release-specific behaviour and certification requirements using official sources. Course links are contextual; no search ranking, certification or employment outcome is guaranteed.
