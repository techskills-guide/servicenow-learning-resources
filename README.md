# ServiceNow Learning Hub

An independent educational resource publishing carefully planned ServiceNow learning guides, one article at a time.

## Website

Once GitHub Pages is enabled for the `main` branch and `/(root)`, the site should be available at:

https://techskills-guide.github.io/servicenow-learning-resources/

## Structure

- `index.html` — homepage featuring the current article
- `blog/` — blog archive and individual educational articles
- `assets/style.css` — responsive layout
- `about.html` — editorial scope and disclosure
- `robots.txt` and `sitemap.xml` — crawl guidance and URL discovery

## SEO notes

Pages include titles, descriptions, canonical URLs, Open Graph metadata, internal links and relevant structured data. Metadata and sitemap URLs assume the GitHub Pages project URL above; update them if the publishing URL changes. The sitemap lists only the active article, not removed articles.

Google Search Console ownership verification must be completed by the site owner. Add the site as a URL-prefix property, verify it using an available method, and submit the sitemap at `sitemap.xml`. A verification token must come directly from Search Console; never invent one.

## Editorial principles

Content is educational and not official ServiceNow documentation. Verify current feature availability, release-specific behaviour and certification requirements using official sources. Course links are contextual; no search ranking, certification or employment outcome is guaranteed.
